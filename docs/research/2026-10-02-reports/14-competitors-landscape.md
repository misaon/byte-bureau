## 1. Executive summary

1. **The "pixel office for agents" niche is crowded but shallow.** Since Feb 2026 at least ~60 GitHub projects visualize coding agents as pixel characters (Pixel Agents 9.5k★, Munder Difflin 8.3k★, Star-Office-UI 7.5k★, clawd-on-desk 6.3k★, claw-empire 1.4k★, Agentshire 1.3k★, agents-observe 0.7k★, claude-office 0.5k★, 3D agent-office 0.5k★, pixtuoid 0.5k★ …). Nearly all are *passive visualizers* of local Claude Code/OpenClaw sessions fed by hooks or `~/.claude/projects` JSONL; most are abandoned within 6–8 weeks (Star-Office-UI, claw-empire, outworked, Agentshire, Claude-Office, codemap all dormant since Mar–Apr 2026). Only Munder Difflin and (to a lesser degree) claw-empire/agent-campus/AgentSystemLabs actually *orchestrate* work from the office view. Nobody ships procedurally generated floors, Sims-style needs/behaviour, or an office that mirrors a full ticket→PR→review→merge workflow.
2. **Orchestration UIs for coding agents have consolidated around git worktrees, not containers.** Paseo (19.2k★, Apache-2.0, desktop/iOS/Android/web/CLI, E2EE relay, plugins, 36+ providers via ACP), Superset (14.8k★, Elastic-2.0, YC P26, iPhone app behind Pro), Emdash (5.9k★, Apache-2.0, 10 issue trackers, SSH remote), Conductor (closed, macOS, $0/$50/$60, cloud workspaces on Vercel sandboxes + mobile), Claude Squad, CCManager, Xum (ex-Mux, AGPL). Superset's README literally says worktrees "do not sandbox processes". Container-based isolation in OSS is limited to OpenHands (Docker runtime), Dagger container-use (low activity), CCManager devcontainer hooks, and hosted products (Boxes.dev, Tembo, Conductor Cloud, Claude cloud sessions, Codex cloud).
3. **The market is brutal for standalone orchestration UIs.** Vibe Kanban (28.2k★) announced its sunset on 2026-04-10 ("the vast majority are free users"); Crystal was discontinued Feb 2026 (→ Nimbalyst); Omnara pivoted from mobile client to a "managed agents API"; Roo Code and coder/agentapi are archived; Codegen was absorbed by ClickUp; Kilo by Anaconda; Rovo Dev is being folded into Jira. HN reception of Omnara's Launch (147 pts) was dominated by "Anthropic/OpenAI could ship this any day" — and they did.
4. **Vendors shipped most of the generic surface in 2026.** Anthropic: Desktop Code tab with parallel worktree sessions, Dispatch-from-phone, PR monitoring, Remote Control (Feb 2026, HN 544 pts), cloud sessions on isolated VMs with self-hosted runners, Routines (Apr 2026, HN 720 pts; schedule/API/GitHub triggers), Projects (coordinator → parallel cloud threads with memory), experimental Agent Teams (lead + teammates, JSON mailboxes, tmux panes), Managed Agents (beta, Apr 2026), Claude Tag in Slack. OpenAI: Codex cloud, Codex app merged into the ChatGPT desktop app, and **Symphony** (27.5k★, Elixir, Apache-2.0: Linear board → isolated autonomous runs → PRs with "proof of work"). Cursor: Projects (Sep 2026, "thousands of subagents" on isolated VMs), self-hosted machines, cloud agents with Slack/CI triggers. Warp Oz: cloud fleet with shared memory and "self-improvement loops".
5. **ByteBureau's genuinely open ground**: (a) an *open-source, local-first, container-isolated, agent-agnostic runtime* that is portable to K8s/RPi (vendors are GitHub-only and cloud-only; OSS peers are worktree-only); (b) a *truthful office simulation of the whole workflow* (Jira/GitLab/Bitbucket/Slack included) rather than a Claude-only tamagotchi; (c) *subscription economics* integrated into the orchestrator (rotation + usage HUD; today split across cc-switch 139k★, claude-swap 3k★, ccusage 18.8k★); (d) E2EE phone control is **not** unique (Paseo, Happy) but can be reused wholesale. Telemetry-driven self-improvement is claimed only by closed vendors (Warp Oz, Qodo) or hype projects (ruflo) — open but unproven.

### 2.1 Inspiration repo: Munder Difflin (chaitanyagiri/munder-difflin)

- **What**: "A local multi-agent harness that works with your existing Claude Code, Codex subscriptions, allows you to run an office of agents." Office of The-Office-themed agents on a 2D Pixi floor; "Michael" is the orchestrator ("GOD agent") that routes work via mailboxes.
- **Stack (package.json @ main, version field 0.4.6 lags releases)**: Electron + electron-vite, React 18, TypeScript, **pixi.js ^8.5.1**, **@xterm/xterm 5.5 (+webgl, fit, unicode11)**, **node-pty**, better-sqlite3, zustand, Monaco + CodeMirror 6 (built-in IDE), react-markdown, i18next, electron-updater, **posthog-node** (telemetry), **localtunnel + tunnelmole** (tunnels), **@openai/agents-realtime** (voice). Dev: electron-builder, @electron/notarize, vite.
- **Source layout**: `src/main` (53 files: PTY, hive, hooks, router), `src/renderer` (157 files: office, terminals, command center), `src/preload`, `src/shared` (34); `tools/mapgen` (3 files — map generation tooling), `prototypes/vde`, `resources/skills` (18), `.claude/skills` (24), `landing-remotion`, `blog` (eleventy; 758 files), `docs/pr-evidence`, `test/fixtures`.
- **How agent activity maps to the office (from the two engineering blog posts)**: floor authored in **Tiled** and exported as `.tmj`; three layer kinds: tile layers (floor/walls/furniture), a **collision layer** (walkable grid), and a **spawn-points object layer** (desks). Seat pool assigns desks first-come-first-served. **BFS** on the walkability grid, 4-directional ("no A* needed at office scale"). Avatars are sliced from a shared walk sheet with **palette recoloring** (skin/hair/shirt recipes), 3 facings with mirroring; a **leg-crop mask** makes seated characters look seated. Stations: terminal (shell commands), file shelf (read/write), mailbox (blocked on human), desk (idle). Movement is driven by **real Claude Code hook events** — "A `PreToolUse` event sends the avatar walking toward the station that matches the tool." Inter-agent messages are **envelopes** flying desk-to-desk on a quadratic arc, **tinted by speech act** (questions cool, agreements warm, refusals red, human escalations distinct). Rendering: single `world` container for camera, `antialias:false`, `roundPixels`, nearest scaling, one shared ticker. "The floor functions as observability rather than decoration."
- **Architecture**: two data planes — *terminal plane* (PTYs, filesystem, git) and *event plane* (hive, hook server, router). Git-based "hive" with atomic-file mailboxes and a single-committer rule; agents "read their memory and drain a mailbox; the router moves messages between inboxes; the GOD agent adjudicates, assigns, and escalates only when it needs you." Circuit breaker ladder "steer → constrain → stop", per-agent autonomy + token budgets, OTel spans, Kanban + Monaco IDE + git rails ("Command Center"), markdown memory mined into a searchable "palace".
- **Agents/backends**: Claude Code, Antigravity (Gemini), Codex, Grok, Kimi Code, Gemini CLI, Qwen, OpenCode, Crush, pi.dev, Copilot CLI, Cursor, custom commands; BYOK via a write-only secret broker; local LLMs through Ollama / LM Studio / vLLM base URLs. Every agent "runs as a real process in a pseudo-terminal (node-pty), byte-for-byte authentic". Missing CLIs show an Install card (v0.5.3+).
- **Isolation**: **none** — host PTYs; "Sandboxes for continuous agent operation with closed laptop" is a roadmap item on the site.
- **Remote/mobile**: site: "Coming soon: Remote control from an app." Inter-machine messaging is E2E-signed/sealed (X25519, XChaCha20, Ed25519; "Keys never leave your machines"). HN commenter asked why E2EE is needed between one's own agents.
- **Telemetry**: anonymous events via PostHog ("buckets and fixed words only, no email, no account id"), documented in TELEMETRY.md; opt-out via settings, `DO_NOT_TRACK`, or building from source (no key compiled in).
- **Pricing**: Free (classic office); **Pro $150/yr launch (normally $200) or $20/mo** — adds the "Stapler" (local Whisper dictation + meeting transcription, English only) and a new sidebar (Tasks, Inbox, Automations, Memory, Capabilities); Teams = custom (piloting with 5 businesses). Author solo (girichaitanya11@gmail.com), "looking for an angel investor" (HN).
- **License**: MIT (code, © 2026 Chaitanya Giri). **Assets**: LimeZu "Modern Interiors – RPG Tileset [16×16]" under the paid *Complete Version* licence ("Credit to LimeZu is required … and must stay in place"); The Office cast portraits are procedural (`portraitArt.ts`).
- **Stats**: 8,259★ / 1,112 forks / 229 open issues; created 2026-05-31; pushed 2026-10-01; releases v0.5.5 (2026-10-01), v0.5.3 (09-25), v0.5.2 (09-09), v0.4.6 (08-27). HN "Munder Difflin – Agent harness to run an office of your clones" 312 pts / 145 comments (2026-08-22, author `chaicodes`); claimed 10K+ users and 30K+ agents spawned within 8 days of the Product Hunt launch.
- **Reception**: praise for whimsy and "cognitive cues that LLMs are characters, not brilliant humans"; criticism: "cringe", "straight ripoff" of The Office IP used to market a product, "the office concept is tedious, use a spreadsheet", UI/notification complaints, requests for role-based pipelines instead of personalities.
- **Limitations for ByteBureau**: no container isolation; Electron weight; hand-authored Tiled map (mapgen exists but undocumented); The Office IP exposure; LimeZu licence forbids redistribution (shipping the raw tileset in an MIT repo is at best a grey area); remote app not shipped; telemetry present.

Takeaways for the office differentiator: (1) every maintained visualizer is <10k★ and most are single-maintainer; (2) feature ceiling today = hooks → states → desk animation + a few whiteboards; (3) no one ties the office to ticket systems, PR state, Slack, or containers; (4) Sims-like "needs" exist only as flavour (bagidea's society, pixtuoid's pets/weather); (5) procedural floors don't exist (munder has an undocumented `tools/mapgen`; pixel-agents has a manual layout editor; pixtuoid auto-fills floors by desk count); (6) HN tolerates the metaphor when it is framed as *observability* and rejects it when it's framed as *cute* ("cringe", "spreadsheet").

### 2.3 Agent orchestration / management UIs

**Paseo (getpaseo/paseo, paseo.sh)** — 19,212★ / 2,240 forks / 977 open issues; TypeScript monorepo; created 2025-10-13; v0.10.2 (2026-09-29); pushed 2026-10-01. License: Apache-2.0 per site/README (GitHub API reports NOASSERTION). Surfaces: native macOS app, **iOS + Android (App Store/Play) with "full feature parity"**, web (app.paseo.sh), CLI, headless daemon. Providers: custom adapters for Claude Code, Codex, OpenCode, Pi, OMP, Antigravity, Muse Code, Copilot "+36 more" via **ACP**; `paseo run --provider claude/opus-4.6 … --worktree feature-x`. Isolation: optional git worktrees. Remote: daemon dials out to an **E2EE relay** (Curve25519 ECDH keypair in `$PASEO_HOME/daemon-keypair.json`; QR/link pairing carries the daemon public key; NaCl `box` XSalsa20-Poly1305; "The relay sees only: IP addresses, timing, message sizes, and session IDs"; relay off by default, consent at pairing); alternatives: direct TCP 127.0.0.1:6767, Tailscale/VPN, Unix socket; optional bcrypt password + DNS-rebinding protection. Relay is open source: **getpaseo/paseo-relay** (Elixir/OTP, Apache-2.0, 92★, WebSocket, validates only the X25519 `hello` frames). Telemetry: "no telemetry, tracking, or forced login". Extras: TypeScript **plugins** (themes, panels, commands, providers; `paseo plugin install <npm|git|dir>`), schedules, heartbeats, agent profiles/skills, voice (local STT), browser tools, TS SDK, public API, **Paseo Hub** (team daemons, GitHub/Slack/Discord triggers, paid team features), community plugins at paseo.cafe. Solo maintainer (`boudra`), "turned down funding offers". HN Show HN 92 pts (2026-06-02): design called "basic tailwind", debate about shipping from a phone. Note: this very workstation already has Paseo skills installed — ByteBureau's owner is a Paseo user; study its daemon/relay/plugin architecture closely.

**Conductor (conductor.build, Melty Labs)** — closed source, macOS only. Agents: Claude Code, Codex, Cursor agents; "bring your own subscriptions and keys". Isolation: local workspaces (worktrees) or **cloud workspaces on Vercel sandboxes (8 vCPU/16 GB, us-east-1)**. Pricing: Free $0 (parallel agents, local), **Pro $50/mo** (cloud workspaces, multiplayer ≤5, API, **mobile app**), Teams $60/user/mo, Enterprise (SAML/SCIM, DPA). Cloud chat messages stored server-side; local sessions private. Changelog cadence ~2/week: 0.89.1 "GPT-6.1 Sol" (2026-09-29), 0.89.0 "Sign in with ChatGPT", 0.87.0 "OpenCode 2.0", 0.86.0 shareable "loadouts", 0.85.0 sections + **routines** + model picker, 0.80 stackable workspaces, 0.78 cloud. ## 5. Risks

1. **Vendor absorption (high, ongoing)**: Anthropic ships weekly (v2.1.287 on 2026-10-01): Desktop parallel worktree sessions, Dispatch, Remote Control, cloud VMs + self-hosted runners, Routines, Projects (coordinator + memory), Agent Teams, Managed Agents, Claude Tag. OpenAI: Codex cloud, ChatGPT app, Symphony. Cursor Projects. Any "manage many Claude sessions" feature is commodity; ByteBureau must not depend on being the only UI. Mitigation: wrap vendor cloud sessions as floors; compete on multi-vendor + non-GitHub workflows + ownership of data.
2. **Monetization/graveyard risk (high)**: Vibe Kanban (28k★) sunset for lack of a business model; Crystal, Roo Code, agentapi, Codegen SDK archived; Omnara pivoted; Rovo Dev folded into Jira; Kilo acquired. Paseo survives as a solo sponsor-funded project; Munder sells a $150/yr Pro tier and seeks angels. Plan the sustainability story (Pro features like Munder's Stapler/sidebar; team hub like Paseo Hub; or stay hobby-scale).
3. **Direct rival: Munder Difflin** — 8.3k★, 10k users, same thesis (office of subscription-backed CLI agents), MIT, with sandboxes and a remote app on its roadmap and a Teams pilot. Also AgentSystemLabs' 3D office (477★ in 5 days) and Pixel Agents' orchestration roadmap. Expect at least one of them to add containers + Jira within months.
4. **Reception risk**: HN split on office metaphors ("cringe", "ripoff", "spreadsheet" vs "genuinely useful cognitive cues"). Position as observability; keep a plain dashboard mode; avoid The Office/Prison Architect trademark-adjacent branding and Anthropic's "Clawd" IP.
5. **Asset licensing**: LimeZu free = non-commercial (Star-Office-UI trap); Complete licence forbids redistribution → cannot live in an MIT repo; JIK-A-4 packs free but terms unverified. Commission or generate original sprites, or use CC0.
6. **Vendor churn breaking integrations**: hooks/JSONL formats and CLI flags change constantly (Claude Code changelog), OpenClaw 2026.4 broke Agentshire, Codex app folded into ChatGPT, docs URLs moved (developers.openai.com → learn.chatgpt.com, factory.ai → factory.com, kilocode.ai → kilo.ai). Isolate adapters behind ACP/plugins; pin versions in containers.
7. **ToS/legal**: automatic multi-account rotation on consumer subscriptions may breach provider terms (unverified); free-claude-code explicitly promises to remove integrations that stop being allowed. Keep rotation opt-in and documented.
8. **Scope**: eight differentiators vs solo-maintainer reality; the field shows single-maintainer projects dying in 6–8 weeks. Sequence: runtime + workflow + office core first; E2EE/mobile via reuse; self-improvement last.
