## 1. Subscription auth policy — the report's "prohibited" framing is OUTDATED/OVERSTATED
Primary sources fetched directly:

  - Current state: "We're pausing the changes to Claude Agent SDK usage described below. For now, nothing has changed: Claude Agent SDK, `claude -p`, and third-party app usage still draw from your subscription's usage limits."
  - => Agent SDK / `claude -p` with a Pro/Max login WORKS today and counts against the plan's limits.
- Agent SDK overview, https://code.claude.com/docs/en/agent-sdk/overview.md
  - Note: "Unless previously approved, Anthropic does not allow third party developers to offer claude.ai login or rate limits for their products, including agents built on the Claude Agent SDK. Use the API key authentication methods described in the Quickstart instead."

- Authentication docs, https://code.claude.com/docs/en/authentication.md

  - Multiple accounts: `CLAUDE_CONFIG_DIR` per account ("work and personal").
  - Credentials: macOS Keychain (fallback `~/.claude/.credentials.json` 0600), Linux `~/.claude/.credentials.json`, Windows `%USERPROFILE%\.claude\.credentials.json`.
  - Precedence: cloud provider > ANTHROPIC_AUTH_TOKEN > ANTHROPIC_API_KEY > apiKeyHelper > CLAUDE_CODE_OAUTH_TOKEN > profiles > subscription OAuth from /login.
  - "`apiKeyHelper`, `ANTHROPIC_API_KEY`, and `ANTHROPIC_AUTH_TOKEN` apply to the CLI and the surfaces that wrap it, including the VS Code extension, the Agent SDK, and GitHub Actions."
- Headless docs, https://code.claude.com/docs/en/headless.md

  - Without --bare, `claude -p` uses the same credentials as interactive sessions (subscription works).
  - Flags verified: --output-format text|json|stream-json, --json-schema, --include-partial-messages, --forward-subagent-text, --continue, --resume <id|path>, --allowedTools, --permission-mode auto|dontAsk|acceptEdits|plan, --permission-prompts none (v2.1.259+), --permission-prompt-tool, --append-system-prompt(-file), --system-prompt, --settings, --mcp-config, --agents, --plugin-dir/--plugin-url, --add-dir, --max-turns, SIGINT/SDK interrupt() to end a turn, SIGTERM exit 143; stream events: system/init (capabilities[], plugins, mcp_servers), system/api_retry, system/plugin_install, permission_denied, assistant/user with parent_tool_use_id (subagent tree), result (total_cost_usd, permission_denials).
  - stdin capped at 10MB; exit code 0/non-zero.

### Practical conclusion for ByteBureau
- Personal use (owner runs ByteBureau locally against their own installed `claude`): same as scripting `claude -p` — supported path (setup-token docs explicitly bless scripts/CI).
- Distributing ByteBureau to others: ByteBureau must NOT "offer claude.ai login" itself. Safe design = "bring your own agent CLI": ByteBureau spawns the user's own installed/authenticated `claude` (or Codex/OpenCode/…) as an external runtime; it never collects, stores or proxies claude.ai OAuth tokens; API-key mode is a first-class alternative; the Claude integration is one plugin among many. Follow branding rules ("Claude Agent", not "Claude Code").
- Policy is in flux (credit program paused; `--bare` may become default). Keep the agent-runtime boundary thin and swappable.
- Jan/Feb 2026 third-party OAuth blocking reported by WinBuzzer/GIGAZINE (news, not primary) — concerns harnesses hitting the API with OAuth tokens directly; not the same as spawning the real CLI.

## 6. Remote Control (verified, https://code.claude.com/docs/en/remote-control.md)
- Transport: local session makes outbound HTTPS only, registers with Anthropic API and polls; server routes messages between web/mobile client and the local session over a streaming connection. "All traffic travels through the Anthropic API over TLS" — i.e. NOT end-to-end encrypted; "the session transcript, including your messages, Claude's responses, and tool activity, is stored on Anthropic servers". Orgs with Zero Data Retention can't enable it.
- Requirements: Pro/Max/Team/Enterprise subscription only (API keys not supported); not available via Bedrock/Vertex/Foundry, any `ANTHROPIC_BASE_URL` gateway/proxy, or apps gateway; needs feature-flag fetching (`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`/`DISABLE_GROWTHBOOK` break it); workspace trust prompt; `claude setup-token` tokens can't start RC sessions.
- Connected device capabilities: live conversation, compaction progress, diff pane (git), pick model & effort, send images/files, push notifications ("Push when Claude decides" / "Push when actions required"), cross-session messaging, Trusted Devices (org enrollment).
- Positioning for ByteBureau: offer what RC cannot — zero-knowledge relay (E2EE), works with API keys / any provider / gateways, multi-agent & multi-project view, office sim; mirror its good UX (diff pane, model/effort control from phone, push on "action required", presence-based push suppression via a presence marker).

## 7. Sandbox environments & secure deployment (verified)
- https://code.claude.com/docs/en/sandbox-environments.md: options = sandboxed Bash tool (OS primitives, no Docker, not native Windows), sandbox runtime `@anthropic-ai/sandbox-runtime` (whole process incl. MCP/hooks; beta; needs bubblewrap+socat on Linux; allow domains api.anthropic.com + claude.ai + platform.claude.com for OAuth refresh), dev container (official example with default-deny iptables firewall; supports `--dangerously-skip-permissions`), custom container, VM (Firecracker etc.; "Docker Sandboxes" = free standalone Docker product giving a microVM with its own Docker daemon + workspace sync, can run Claude Code), cloud sessions. `--dangerously-skip-permissions` refuses to run as root → run container as non-root.
- https://code.claude.com/docs/en/agent-sdk/secure-deployment.md: hardened `docker run` profile (--cap-drop ALL, no-new-privileges, seccomp, --read-only, tmpfs, --network none + Unix-socket proxy on host, --memory/--cpus/--pids-limit, --user 1000:1000, code mounted ro) ; credential proxy pattern (agent never sees secrets; `ANTHROPIC_BASE_URL` → host proxy injects key; HTTP(S)_PROXY; Envoy credential_injector / mitmproxy / LiteLLM); gVisor runsc; Firecracker + vsock; never mount ~/.ssh ~/.aws ~/.config; `NODE_USE_ENV_PROXY=1` for Node 24+ fetch.
- Feature availability (https://code.claude.com/docs/en/feature-availability.md): CLI, Agent SDK, subagents, hooks, skills, plugins, MCP, checkpoints, sandboxing, Workflows, OTel work on every provider. Subscription-only: cloud sessions, mobile, Slack, Desktop, Routines, Ultrareview, Remote Control, Chrome, computer use, Artifacts, voice. Channels/Advisor/Fast mode: Claude API only (subscription or Console).
